Mekan aramanın en yorucu kısmı mekan bulmak değil, gelen cevapları karşılaştırmak. Bir mekan "kişi başı 900 TL" diyor, diğeri "180 kişi için toplam 210.000 TL", üçüncüsü "gelin de konuşalım" diyor. Üçü de aynı şeyi sattığını sanıyorsunuz ama aslında üç farklı paketten bahsediyorlar.

Bu rehber iki şeyi çözüyor: mekana ne yazacağınızı ve gelen cevapları nasıl aynı birime indirgeyeceğinizi.

## Teklif istemeden önce netleştirmeniz gereken 8 bilgi

Mekan bu sekiz bilgi olmadan size gerçekçi fiyat veremez. Eksik bilgiyle istenen teklif, sonradan "ama siz şunu söylememiştiniz" diye değişir.

**1. Tarih ve iki alternatif.** Tek tarih verirseniz pazarlık gücünüz sıfır olur. İki alternatif tarih, özellikle biri hafta içi veya sezon dışıysa, mekanın size farklı fiyat vermesinin kapısını açar.

**2. Davetli aralığı.** "200 kişi" demeyin, "180–220 kişi" deyin. Kesin sayı vermek sizi garanti kişi sayısına erken bağlar.

**3. Etkinlik saati ve süresi.** Öğle mi akşam mı, kaçta başlayıp kaçta bitecek. Fazla mesai ücreti bu bilgiden hesaplanıyor.

**4. Menü tipi.** Yemekli mi, kokteyl mi, yemeksiz mi? Kişi başı fiyatı en çok değiştiren kalem bu.

**5. Alkol tercihi.** Alkollü, alkolsüz veya kendi alkolünü getirme. Türkiye'de kişi başı fiyatı ikiye katlayabilen tek değişken.

**6. Dış tedarikçi niyetiniz.** Kendi fotoğrafçınızı, DJ'inizi veya pastanızı getirecek misiniz? Çoğu mekan buna ücret uyguluyor ve bunu teklifte yazmıyor.

**7. Bütçe bandınız.** Üst sınırınızı değil, bir aralık verin.

**8. Olmazsa olmaz üç özellik.** Kapalı alan garantisi, otopark, nikah alanı, bebek bakım odası — hangisi sizin için zorunluysa baştan söyleyin.

## Bütçenizi söylemeli misiniz?

Söylemelisiniz, ama sayı olarak değil aralık olarak.

Bütçe vermezseniz mekan ya en pahalı paketini gönderir ya da "görüşelim" der. İkisi de zaman kaybı. Üst sınırınızı tek sayı olarak verirseniz, teklif tam o rakamın üstünde gelir.

"Kişi başı 800–1.000 TL bandındayız" demek ikisinin ortası: teklif gerçekçi gelir, tavanınız açığa çıkmaz.

## Gelen teklifleri aynı birime indirgeme

Teklifler farklı formatta geldiği için doğrudan karşılaştırılamaz. Hepsini tek bir sayıya indirmeniz gerekiyor: **gerçek kişi başı**.

| | Mekan A | Mekan B | Mekan C |
|---|---|---|---|
| Yazılı kişi başı fiyat | | | |
| Garanti kişi sayısı | | | |
| Dahil olanlar | | | |
| Hariç olanlar | | | |
| Sabit ekstralar toplamı | | | |
| Saatlik ekstralar | | | |
| **Gerçek toplam** | | | |
| **Gerçek kişi başı** | | | |
| Teklif geçerlilik tarihi | | | |
| Kapora oranı | | | |
| İptal şartı | | | |
| Yanıt süresi | | | |

Hesap şöyle işliyor:

```
(garanti kişi sayısı × kişi başı fiyat)
+ sabit ekstralar
+ (saatlik ekstralar × saat)
= gerçek toplam

gerçek toplam ÷ beklediğiniz gerçek davetli sayısı
= gerçek kişi başı
```

Dikkat: bölen, garanti kişi sayısı değil **gerçekten geleceğini düşündüğünüz sayı**. 200 kişi taahhüt edip 170 kişi gelirse, 200 kişinin parasını ödeyip 170 kişiyi ağırlarsınız — gerçek kişi başınız yazılı fiyattan yüksek olur.

## Teklifte kırmızı bayraklar

Aşağıdakilerden biri varsa, o mekanla ilerlemeden önce iki kez düşünün. Her birinin yanında nasıl test edeceğinizi yazdık.

**Yazılı teklif vermiyor, sadece telefonda fiyat söylüyor.** Test: "WhatsApp'tan yazılı gönderebilir misiniz?" deyin. Direnç gösteriyorsa sebebi vardır.

**Mekanı görmeden kapora istiyor.** Test: "Önce gezmek istiyoruz" deyin. Baskı devam ederse uzaklaşın.

**"Bu fiyat sadece bugün geçerli" baskısı yapıyor.** Gerçek mekanlar teklifini en az birkaç hafta geçerli tutar. Aciliyet baskısı satış tekniğidir.

**Sözleşme metnini önceden göndermiyor.** Test: "Sözleşme örneğinizi inceleyebilir miyiz?" Göndermiyorsa içinde görmenizi istemediği bir madde vardır.

**Garanti kişi sayısını açıklamıyor.** Bu, faturanızı en çok büyütebilecek kalem. Net cevap alamıyorsanız teklif eksiktir.

**Dahil/hariç listesi veremiyor.** "Her şey dahil" cümlesi tek başına hiçbir şey ifade etmez. Listesini isteyin.

**Nakit ödemede ısrar ediyor, fatura vermiyor.** Hem vergisel olarak sorunlu hem de bir uyuşmazlıkta elinizde belge kalmaz.

## Pazarlıkta gerçekten işe yarayan 6 kaldıraç

Mekanlar genellikle fiyat kırmaktansa ekstra hizmet vermeye daha açıktır. Pazarlığı "indirim" üzerinden değil "bu fiyata şunu da ekleyin" üzerinden kurun.

1. **Hafta içi veya pazar günü.** Cumartesi akşamı en pahalı dilimdir; esnekliğiniz varsa en güçlü kaldıracınız budur.
2. **Sezon dışı tarih.** Kasım–Mart arası mekanların boş kaldığı dönem.
3. **Erken rezervasyon.** Uzun vadeli rezervasyon karşılığında fiyat kilidi isteyin — zam yapılamayacağını sözleşmeye yazdırın.
4. **İkinci etkinliği aynı mekana verme.** Kına veya nişanı da aynı yerde yapacaksanız paket indirimi mümkün.
5. **Yüksek oranlı ön ödeme.** Nakit akışı mekanın işine gelir, karşılığında talep edin.
6. **Davetli sayısını yukarı taahhüt.** Kişi başı fiyat, toplam ciro büyüdükçe düşebilir.

7. Saat kaça kadar yüksek sesle müzik yapılabiliyor?
8. Nikah mekanda kıyılabiliyor mu?
9. Açık alan varsa yağmurda plan ne, kapalı alan kaç kişi alıyor?
10. Takı merasiminde güvenlik desteği veriyor musunuz?
11. Düğünden önce prova veya dekor kurulumu için ne zaman girebiliriz?
12. Son üç düğününüzden fotoğraf gösterebilir misiniz?

## Süreç ne kadar sürüyor?

Pratikte işleyen akış şöyle: **5–7 mekandan teklif alın**, bunlardan **3 tanesini gezin**, son **2 mekanla pazarlık** yapın.

Yanıt süresi başlı başına bir sinyal. Teklifinize 48 saat içinde dönmeyen bir mekan, düğün günü yaşanacak bir aksaklıkta da geç dönecektir.

Rezervasyon zamanlamasında yaygın öneri, yoğun sezon (Mayıs–Ekim, hafta sonu) için 9–12 ay, kış ayları için 4–8 ay öncesinden harekete geçmek yönünde. Bu süreler kesin kural değil, sezon yoğunluğuna göre değişiyor.

## Tekliften sözleşmeye

Teklifi kabul ettiğinizde iş bitmiyor. Teklifte yazan her kalemin sözleşmeye de geçtiğinden emin olun. Teklifte "ses sistemi dahil" yazıp sözleşmede yazmıyorsa, düğün günü o kalem ücretli hâle gelebilir.

Kapora vermeden önce sözleşmeyi mutlaka okuyun ve fiyat artışı yasağı maddesinin bulunduğundan emin olun. Sezon başında anlaşıp yaz aylarında düğün yapan çiftlerin sık karşılaştığı sorun, aradaki aylarda gelen zam talebidir.

## Sıkça Sorulan Sorular

### Kaç mekandan teklif istemeliyim?

5–7 mekandan teklif alıp 3 tanesini gezmek dengeli bir yaklaşım. Daha azı karşılaştırma imkânı bırakmıyor, daha fazlası karar vermeyi zorlaştırıyor ve süreci uzatıyor.

### Mekan fiyat söylemiyor, sadece "gelin görüşelim" diyor. Ne yapmalıyım?

Gitmeden önce yazılı bir fiyat bandı isteyin. Bütçenizin çok üstündeki bir mekanı gezmek zaman kaybı. "Kişi başı hangi aralıkta çalışıyorsunuz" sorusu genelde cevap alır. Cevap gelmiyorsa bu da bir bilgi.

### Teklif ne kadar süre geçerli olur?

Çoğu mekan 15–30 gün geçerlilik verir. Geçerlilik süresi teklifte yazılı değilse mutlaka sorun ve yazdırın — aksi hâlde karar verdiğinizde fiyat değişmiş olabilir.

### Teklif aldıktan sonra pazarlık yapmak ayıp mı?

Hayır, sektörde beklenen bir davranış. Ancak fiyat kırmaya zorlamak yerine ek hizmet istemek daha yüksek başarı oranına sahip: fazla mesai saatinin dahil edilmesi, ses sistemi, nikah alanı düzenlemesi gibi.

### Gezmeden kapora vermeli miyim?

Hayır. Fotoğraflar mekanın gerçek durumunu, tavan yüksekliğini, ses akustiğini, otopark yeterliliğini ve çevre gürültüsünü göstermez. Kapora öncesi mekanı görmek istisnasız kuraldır.
